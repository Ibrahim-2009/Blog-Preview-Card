# Blog-preview-card

Blog preview card Frontend Mentor Challenge

## 🚀 Overview

This project focuses on building a visually appealing blog card component with proper layout, typography, and interactive elements.

## 🛠️ Built With

* HTML5: semantic structure
* CSS3: Flexbox for layout
* CSS: variables for consistent styling
* Google Fonts: Figtree Font

## 🎯 Features

* Clean card-based UI design
* Custom shadow and border styling
* Hover effect on the article title
* Well-structured layout with proper spacing
* Responsive design for smaller screens

## 📚 What I Learned

* Creating card layouts with consistent spacing
* Using box-shadow effectively for visual depth
* Handling hover states for better interactivity
* Writing cleaner and more organized CSS
